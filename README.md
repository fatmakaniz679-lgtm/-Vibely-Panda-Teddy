# Vibely Panda Teddy — Fresh rebuild

A clean Android application project (version 2.0.0) with an offline, local pet-care experience: Panda/Teddy selection, feeding, bathing, play, sleep, room navigation, wardrobe entry point, coins, stat meters, and local save state.

## Build
GitHub Actions builds `app-debug.apk` on every push to `vibely-rebuild-clean`. Open the Actions tab and download the artifact named `Vibely-Panda-Teddy-FRESH-APK`.

## Honest feature note
This is a fresh functional 2D pet-care app foundation. It does not yet contain rigged 3D models, skeletal animations, or a true 3D room renderer; those require dedicated 3D assets and integration and are not represented as completed here.
